# 禁用油桶、煤气罐、氧气瓶和激光指示盒

这是《求生之路 2》的服务端 SourceMod 插件，也可用于装有 SourceMod 的本地房主。

## 安装

1. 服务端先安装 Metamod:Source、SourceMod 1.12；使用 SourceMod 自带的 SDKTools、SDKHooks，无需其他插件或额外 gamedata。
2. 将安装包里的 `left4dead2` 文件夹合并到游戏/服务器根目录的同名文件夹。
3. 重启服务器或更换地图。可以在服务器控制台输入 `sm plugins load l4d2_remove_props` 热加载；为完整检查地图初始物资，建议换图。
4. 输入 `sm plugins list`，确认 `L4D2 Remove Props` 已加载；管理员可输入 `sm_removeprops_status` 查看开关和本图已清理数量。

核心文件是 `left4dead2/addons/sourcemod/plugins/l4d2_remove_props.smx`。`scripting` 中的 `.sp` 是源码，不需要游戏自行编译。本插件独立安装，不替换已有的物资刷新插件。

## 默认效果

- 清理可搬运的普通汽油桶、煤气罐、氧气瓶和激光指示盒。
- 处理地图已有物品、回合重开，以及游戏/其他插件后续生成的对应实体。生成后在下一帧安全删除，并阻止待清理物品被正常使用/触碰拾取；每两秒补查一次延后设置模型的物品。
- 同时识别武器实体与对应模型的物理实体。不删除普通场景杂物、固定大型燃油爆炸桶或烟花箱。
- 随机升级补给点正常保留；如果其生成激光指示盒，再清理该盒子，不连带删除燃烧弹、爆炸弹补给包。不清除枪械已经获得的激光升级。
- 默认保留使用非零皮肤的任务油桶，包括标准加油任务/清道夫油桶。第三方地图的任务脚本和模型可能不同，不能保证识别所有自定义任务油桶；这类地图可关闭油桶清理项。
- 热加载时不强删玩家正在携带的物品；放下后会被清理。卸载或关闭插件不会立即补回已经删除的物资，需要重开地图。

## 配置

文件：`left4dead2/cfg/sourcemod/l4d2_remove_props.cfg`。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `l4d2_remove_props_enable` | `1` | 总开关 |
| `l4d2_remove_props_gascan` | `1` | 清理可搬运油桶 |
| `l4d2_remove_props_propane` | `1` | 清理煤气罐 |
| `l4d2_remove_props_oxygen` | `1` | 清理氧气瓶 |
| `l4d2_remove_props_laser` | `1` | 清理激光指示盒 |
| `l4d2_remove_props_keep_scavenge` | `1` | 保留任务油桶；设为 `0` 则连任务油桶也删除 |

全部油桶都禁用时，将最后一项改为：

```cfg
l4d2_remove_props_keep_scavenge "0"
```

这样会影响依赖加油的关卡和清道夫模式。控制台修改参数立即应用；永久保存请修改配置文件，再执行 `exec sourcemod/l4d2_remove_props.cfg` 或换图。

## 验证

已使用随工作区提供的官方 SourceMod 1.12 编译器编译，启用 `-E`（警告视为错误）。未在实际游戏服务器中进行运行测试。

建议在测试房验证：

1. 普通地图中的红色油桶、煤气罐、氧气瓶消失；其他物资仍在。
2. 死亡中心第二关枪店的激光盒消失，燃烧弹/爆炸弹补给包不受此插件影响。
3. 死亡中心终章的任务油桶仍能完成加油；将 `keep_scavenge` 改为 `0` 后任务油桶也消失。
4. 重开回合、换图、热加载后规则继续生效，`addons/sourcemod/logs` 中没有本插件报错。
